# calculaterTkinter
A Windows-style calculator built with Python Tkinter.

A Windows 11 style calculator built using Python and Tkinter.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Square
- Square Root
- Percentage
- Reciprocal
- Backspace
- Dark Theme

## Requirements

- Python 3.10+
- Tkinter

## Run

```bash
python calculator.py
```
